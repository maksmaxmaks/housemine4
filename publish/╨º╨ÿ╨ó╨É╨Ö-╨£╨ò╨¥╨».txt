ПАПКА ПУБЛИКАЦИИ
  modpack/          <- сюда кладёте файлы своей сборки (mods, config, resourcepacks, shaderpacks, options.txt ...)
                       структура такая же, как в папке .minecraft вашей рабочей сборки
  pack.config.json  <- версия Minecraft, загрузчик, адрес сервера, ссылки, описание обновления
  news.json         <- новости
  site/             <- создаётся командой "npm run pack"; ЕГО содержимое выкладываете на хостинг

Чтобы выпустить обновление:  1) поменяйте файлы в modpack  2) (по желанию) допишите changelog в pack.config.json
                             3) npm run pack   4) загрузите папку site на хостинг (заменив старую)
Игроки увидят уведомление «Доступно обновление» и обновятся одной кнопкой.
Подробно — в README.md в корне проекта.
